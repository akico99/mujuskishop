# 리조트 고정 객실요금 적용 계획

목표: 사용자가 제공한 2026년 12월~2027년 2월 사진의 1실·1박 요금을 원 단위로 저장하고 직접 금액 입력을 대체한다.

- [x] 날짜별 요금 모듈과 전체 86일 검증 테스트: 비수기 123/160/190천원, 준성수기 160/210/245천원, 성수기 260/355/405천원, 극성수기 340/440/520천원.
- [x] 견적 UI: 숙박일(빈 값은 이용일), 박수, 객실 수. 각 박별 요금을 합산하고 복사할 답변에도 표시한다.
- [x] 표에 없는 날짜, 날짜 없음, 잘못된 박수는 최종 총액 확정 금지. 예약 화면 객실 수 유지.
- [x] 요금표 Markdown 저장, 전체 테스트, 브라우저에서 연박·날짜변경·초기화·미정 날짜 검증 후 기존 GitHub Pages 배포 확인.

기존 단일 HTML 구조를 유지하되 순수 날짜 계산은 room-prices.js로 분리한다. 객실 요금에는 렌탈 쿠폰을 적용하지 않는다. 체크인 날짜 기준이며 사진의 12.3은 123,000원으로 해석한다.

검증: node --test 3/3 통과(달력 86일 전체 대조). ego-browser로 3박 3,876,000원, 날짜/매장 전환, 쿠폰 객실 제외, 미정 날짜·잘못된 박수, 초기화, 예약 객실 수 유지 확인. 배포는 커밋 후 공개 페이지에서 확인한다.
